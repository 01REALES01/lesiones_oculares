# Nombre del Proyecto

## Resumen ejecutivo

**Contexto**: La detección y análisis de retinografías es fundamental para el diagnóstico precoz de patologías oculares. Sin embargo, el proceso es manual, requiere experiencia y es susceptible a errores humanos.

**Problemática / Oportunidad**: La falta de herramientas accesibles que integren modelos de IA para segmentación, clasificación y detección de lesiones limita la capacidad de los profesionales y estudiantes para interpretar imágenes de forma rápida y consistente.

**Solución Propuesta**: Desarrollar una plataforma web que permita cargar retinografías, seleccionar entre tres modelos de IA y obtener resultados con métricas de desempeño. La plataforma está diseñada como apoyo clínico/educativo, no como herramienta diagnóstica definitiva.

**Alcance General**: 
- Backend API (FastAPI) con orquestación de modelos.
- Frontend interactivo (React + Vite) para carga y visualización.
- Registro de inferencias e historial.
- Documentación completa (manual de usuario, requerimientos, evaluación de modelos).

**Valor Añadido**: Facilita la educación y el tamizaje ocular, mejora la reproducibilidad de análisis, reduce tiempos de interpretación y brinda métricas verificables que soportan la toma de decisiones clínicas bajo supervisión.
